# MK Studio Car Detailer

Site estático completo em HTML, CSS e JavaScript, com imagens locais.

## Abrir no computador

Abra `index.html` no navegador. Mantenha `assets/` e `servicos/` junto dele.

## Publicar pelo GitHub Desktop

1. No repositório `mk-car-2`, clique em **Repository > Show in Explorer**.
2. Extraia este ZIP e copie seu conteúdo para essa pasta. O `index.html` deve ficar diretamente na raiz do repositório.
3. Não copie apenas o ZIP e não crie uma pasta adicional dentro do repositório.
4. Volte ao GitHub Desktop. Em **Changes**, selecione os arquivos.
5. Em **Summary**, escreva `Adicionar site MK Studio Car Detailer`.
6. Clique em **Commit to main**, depois **Push origin**. Se aparecer **Publish repository**, use esse botão.

## Publicar na Vercel

1. Na Vercel, escolha **Add New > Project** e importe `mk-car-2` do GitHub.
2. Use o nome de projeto `mkstudio-cardetailer`.
3. Framework: **Other**. Root Directory: raiz do repositório (sem subpasta).
4. O arquivo `vercel.json` configura publicação estática sem instalação ou build.
5. Clique em **Deploy**. O endereço `mkstudio-cardetailer.vercel.app` depende de estar disponível.

## Conteúdo

- `index.html`: página inicial.
- `servicos/`: 13 páginas de serviços.
- `assets/`: logo e fotografias.
- `style.css`, `app.js`, `motion.js`: visual e interações.

Os preços são fictícios para demonstração. Os links de WhatsApp e Instagram já estão configurados.
